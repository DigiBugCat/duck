🦆 duck for iOS

Mobile dashboard for the cassandra stack — chat with hub sessions, approve trades with a swipe, watch the portfolio and the flock. No file sync, hub-only.

🗂
01
Sessions
The duck picker, mobile: live tmux sessions on the hub with Claude's pane-title task summaries, looped sessions pinned, swipe-to-kill.
 💬
02
Session Chat
Chat into a running session — ⏺ turns, ⎿ tool hooks, inline permission approve/deny, camera button for the clipboard bridge.
 ⇄
03
Trade Approvals
Tinder for trades. Swipe right to approve, left to deny — cards carry the order, live quote, position context, and the agent's rationale. Drag works in this mock.
 ◔
04
Portfolio
Schwab positions via cassandra-schwab-broker — total value, day P/L, per-position sparklines, and agent risk alerts.
 𓅮
05
Flock
Automations and runs from flock-server :8787 — heartbeats, crons, event gates; fire / pause from the phone.

All data shapes are real: sessions mirror duck's Sess (tmux + pane_title), trades use the schwab-broker position/quote format, automations mirror flock's Automation/Run domain types. The app would speak to flock-server's existing REST + WebSocket API over Tailscale — no new backend needed for v1.
