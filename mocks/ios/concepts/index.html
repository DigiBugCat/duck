🦆 duck × robinhood — six concepts

Same product, same real data sources, six theses. Every concept has the Robinhood DNA — giant money number, scrubbable chart, range pills, P/L-reactive color, a celebration — interpreted differently. All work full-bleed on a real iPhone.

★ the lean
06
Hybrid
Pulse × Feed — with real options
Pulse's silent-luxury skeleton, Feed's agent voice as a quiet narrative layer. First concept with accurate options positions: covered calls, CSPs, and long calls grouped under their underlyings with Greeks, DTE, and assignment risk.
Try: the NVDA covered-call leg (assignment warning, earnings Thursday) · the roll proposal in Trades · option leg detail with Greeks
01
Pulse
Silent luxury — the faithful minimal take
Near-black, one sea-glass green that flips rose on down days, extreme restraint. If in doubt, remove it.
Try: scrub the chart · slide-to-approve a proposal (particle burst + count-up) · tap the balance for privacy blur · 3M range flips the UI red
02
Terminal
Information density as luxury
Bloomberg-grade research one thumb-tap away: short interest, insider ledger, senate trades, analyst target bands, valuation vs history. All monospace, amber on black.
Try: hold the ticker strip to freeze it · NVDA dossier modules (spring collapse) · long-press a row → command sheet → queue a trim → ORDER FILLED celebration
03
Feed
Your money's group chat
A private feed where every poster works for you — agent insights, fill receipts, morning briefs, milestones. Warm paper + ink. Tabs: Feed / Agents / Trades / Portfolio (full scrub-chart screen).
Try: double-tap a card (heart pop) · approve the NVDA trim inline (confetti) · scroll to the $285k milestone count-up · Portfolio tab → scrubbable chart
04
Stack
A morning ritual, not a feed
The day arrives as one finite card deck. Swipe up = read, right = approve, left = skip, tap = 3D flip for the data back. Cream paper, serif headlines, done-feeling when it empties.
Try: the three-gesture vocabulary · flip a card (every back has a scrubbable chart) · wrong-gesture rubber-band · clear the stack for the 🪺 done state + recap
05
Glance
Calm control room
Ten iOS-widget tiles — whole financial life in 3 seconds. Tiles FLIP-expand into full screens; long-press for jiggle edit mode with drag-reorder.
Try: expand the portfolio hero tile → full scrub chart · long-press → jiggle mode → drag tiles around · approvals tile → inline swipe deck

All six share the audited data layer (../DATA.md): broker positions/quotes, market-research MCP (intraday candles, news, earnings, insider/senate/short-interest), flock proposals over the hub. AirDrop any file to a phone — they all go full-bleed with safe-area insets.
