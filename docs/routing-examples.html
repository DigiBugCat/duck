What goes where

Two kinds, not three surfaces. Static content is an artifact — a page at a URL, with the terminal as an optional porthole. Dynamic content gets a window — the duck-owned chromium on the client machine. Nothing else exists.

Static → artifact

No time, no interaction. If a screenshot of it loses nothing, it's an artifact.

  • ●Design docs & reviewsWINDOW.md itself, ROUTINES.md, a PR walkthrough with code excerpts
  • ●Reports & digeststest-run summary, the morning fleet digest, a bug investigation writeup
  • ●Tables & comparisonsbenchmark results, dependency audit, session inventory
  • ●Static chartsa rendered line chart of sync latency — the image, not a live feed
  • ●Diagramsthe fleet SVG, an architecture sketch, a sequence diagram
  • ●Imagesa screenshot to look at, a generated figure — formerly chafa's job

Dynamic → window

Time, interaction, or your pen on it. If it moves or talks back, it's a window thing.

  • ◆Animations & simulationsa boids run, a physics toy, an animated algorithm visualization
  • ◆Live dashboardsstreaming fleet metrics, a tail of build output with sparklines
  • ◆Interactive explorationsa filterable dataset, a zoomable flame graph, a map
  • ◆Anything you'll mark upreview a mock and circle the wrong part; highlight a number and comment "off by 10×" — the agent queries your marks back
  • ◆Web apps & prototypesa spiked UI you want to actually click through
  • ◆Video / heavy motionanything the ~2–3 MB/s escape stream could never carry
duck preview

Not a third kind — a viewport. The terminal porthole onto the same artifact: micro for markdown, lynx/carbonyl for html. Cells only, zero pixel machinery. For the in-flow glance when you don't want to leave the pane.

Edge cases, called

ContentGoes toWhy
Chart that could be liveartifactDefault static. Promote to window only when the liveness is the point.
Big document you'll annotatewindowMarkup is interaction — the static/dynamic line is about what you do, not the bytes.
Screenshot for the agent's eyesartifact (or just Read)Nothing renders to a human at all; `snap` already covers it.
Slideshow / carouselartifactPaging isn't interaction, it's reading. Scroll it.
Agent demoing a UI to youwindowDuck drives the page via CDP while you watch — custody is the feature.
Quick `htop`-style monitoringterminal (spawn)It's a terminal program, not rendered content. Sidebar as always.
