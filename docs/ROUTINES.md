# ROUTINES — removed (tombstone)

The routines subsystem — scheduled/standing executors, the `duck routines`
verbs, the ⏰ roster tab, heartbeats, the report courier, and the
manager/motherduck org chart — was removed from duck. duck is now scoped to
its layer-1 role: the human-driven interactive workspace (tmux session +
sidebar panel, spawn/reply/resume/fork agents, preview/render/window
artifacts, pads, and the workflow engine).

The self-driven, standing-agent capability is being reborn as a separate
project, **ducklings** (an actor-model runtime). See
[`briefs/ducklings-actor-model.md`](briefs/ducklings-actor-model.md).
